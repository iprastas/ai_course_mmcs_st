# Задание 1 (неделя 2)

Агент-справочник по базе мест Ростова: пять инструментов, цикл без фреймворка,
метрики pass@1 / pass^3 и A/B описаний инструментов.

- Условия и рубрика: [../assignment.md](../assignment.md)
- **Отчёт с метриками и разбором ошибок: [report.md](report.md)**
- Прогоны (JSONL-журналы): [runs/](runs/)

## Файлы

| Файл | Что делает |
|---|---|
| `tools.py` | 5 инструментов над `../practice/poi.sqlite` и их JSON-схемы в двух вариантах описаний: `short` и `full` |
| `tasks.py` | 10 задач: вопрос, ожидаемый инструмент и аргументы, эталон из базы, судья ответа |
| `agent.py` | цикл model → tool_calls → наблюдения → model: лимит шагов, ошибки как наблюдения, учёт usage и цены, журнал JSONL |
| `check.py` | метрики (pass@1, pass^3, Вильсон 95%), A/B, CLI |
| `../../check.py` | переходник в корне, чтобы команда работала из корня репозитория |
| `../../tests/test_assignment.py` | 12 тестов чистых функций без API |

## Запуск на чистой машине

Нужны Python 3.12 и [uv](https://docs.astral.sh/uv/). Из корня репозитория:

```bash
uv sync                          # зависимости
cp .env.example .env             # вписать OPENAI_API_KEY, OPENAI_BASE_URL, MODEL
uv run pytest                    # тесты, без обращения к API
uv run python check.py --n 3     # 10 задач × 3 прогона, вариант full
uv run python check.py --ab --n 3  # A/B: short и full по 3 прогона
```

Прогоны пишутся в `runs/*.jsonl` (одна строка — один прогон: шаги, вызовы,
токены, цена, вердикт). `.env` с ключом в коммит не попадает.
